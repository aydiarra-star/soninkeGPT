Sur les 19 formes restantes, **1 est résolue** (Taŋe), **5 sont résolues partiellement** (le sens visé est certain, la graphie ou la forme isolée reste à confirmer) et **13 restent non résolues** : ni la forme du document, ni son second élément lorsqu'elle est composée, n'apparaissent dans les dix sources consultées.

Point commun des 13 non résolues : ce sont presque toutes des **composés écrits avec un trait d'union** (Kit-soro, Tange-golle, Tange-muru, Tegi-soro, Kuntu-bunyi, Qunyu-bunyi). Le guide d'écriture SIL indique que ce trait d'union sert, dans l'enseignement aux débutants, à montrer les composants d'un mot composé. Le document a donc probablement été établi dans une variété ou une tradition de transcription que les dictionnaires disponibles ne couvrent pas.

## Détail

### Résolu

**`Taŋe`** — le document dit « jambe »

- Notion attestée : front
- Forme attestée : teŋe ; tenŋe ; taηe
- Analyse : Le document sépare Taŋe (jambe) et Teingé (front). Les sources ne connaissent qu'une forme, notée teŋe ou taηe, pour le front.
- Sources : S1,S2,S5,S6,S8
- À faire : Rattacher Taŋe au front comme variante de Teingé, et retenir tanxare pour la jambe.

### Résolu partiellement

**`Kit-qasse`** — le document dit « poignet »

- Notion attestée : poignet
- Forme attestée : kittinxanne ; kitun qanne
- Analyse : Composé « main + cou ». Le poignet se dit littéralement « le cou de la main » : kitte (main) + xanne / qanne (cou). « qasse » correspond à cette base « cou ».
- Sources : S5,S6
- À faire : La composition confirme le sens. La graphie « qasse » reste à faire confirmer.

**`Kit'e`** — le document dit « bras »

- Notion attestée : main (et bras)
- Forme attestée : kitte ; kíttè ; kitu
- Analyse : Le document présente « Kit'e / Kitte » comme une seule entrée. Kit'e est la graphie du même mot kitte, que le guide SIL glose « la main, le bras ».
- Sources : S1,S2,S3,S5,S7,S8
- À faire : Conserver Kit'e comme variante de Kitte. Pour « bras » au sens strict, retenir xuli.

**`Tange`** — le document dit « pied »

- Notion attestée : pied
- Forme attestée : ta ; taanu (pluriel)
- Analyse : La base attestée est ta (pied, jambe), taanu au pluriel. « Tange » en est un élargissement attesté dans les composés (tanxare « jambe », tandoronme « orteil »).
- Sources : S1,S3,S5,S8
- À faire : Faire confirmer la forme isolée « Tange » ; la base sûre est ta.

**`Kuru`** — le document dit « genou »

- Notion attestée : genou
- Forme attestée : xurungo ; xurngo ; qúrúngò
- Analyse : Aucune source ne note « kuru » seul. La forme attestée est xurungo / qúrúngò, dont kuru peut être une réduction ou une variante de parler.
- Sources : S1,S2,S3,S5,S8
- À faire : Faire confirmer par le référent ; la forme sûre est xurungo.

**`Xill'e`** — le document dit « os »

- Notion attestée : os
- Forme attestée : xotte ; qóttè
- Analyse : Aucune source ne note « xill'e ». L'os est attesté sous xotte / qóttè ; le rapprochement repose uniquement sur la forme-source xotte.
- Sources : S3,S4,S5
- À faire : Faire confirmer la graphie ; la forme sûre est xotte.

### Non résolu

**`Kit-soro`** — le document dit « doigt »

- Notion attestée : doigt
- Forme attestée : doronme ; kittindoromu ; doronmu
- Analyse : Composé « main + soro ». Le doigt est attesté sous doronme ; « les doigts de la main » sous kittindoromu. Mais « soro » n'est pas le doigt dans les dictionnaires consultés : sooro = intelligence (ODA), sòró = faire cuire (Creissels, Soninkara).
- Sources : S1,S2,S4,S5,S8,S9,S10
- À faire : Le sens visé est clair (doigt), la forme « soro » ne l'est pas. À faire trancher.

**`Tange-soro`** — le document dit « orteil »

- Notion attestée : orteil
- Forme attestée : tandoronme ; tandoore ; tandoromu
- Analyse : Composé « pied + soro », parallèle à Kit-soro. L'orteil est attesté sous tandoronme / tandoore, littéralement « doigt de pied ». Même réserve sur « soro ».
- Sources : S1,S2,S5,S8
- À faire : Le sens visé est clair (orteil), la forme « soro » reste à confirmer.

**`Tange-golle`** — le document dit « mollet »

- Notion attestée : mollet
- Forme attestée : ɲollenme
- Analyse : Composé « pied/jambe + golle ». Le mollet est attesté sous ɲollenme. « golle » est attesté séparément au sens de « mortier » et « travail » (ODA), pas de « mollet ».
- Sources : S4,S5
- À faire : La notion est attestée sous ɲollenme ; le composé du document ne l'est pas.

**`Tange-muru`** — le document dit « cheville »

- Notion attestée : cheville
- Forme attestée : taxaane ; sellinñelle ; ɲollenme
- Analyse : Composé « pied/jambe + muru ». La cheville est attestée sous taxaane et sellinñelle. « muru » est attesté au sens de « prépuce » (ODA), pas de « cheville ».
- Sources : S4,S5,S8
- À faire : Trois formes concurrentes pour la cheville. À faire trancher par le référent.

**`gnougnou`** — le document dit « lèvre »

- Notion attestée : lèvre
- Forme attestée : soome ; soomu ; soomon-fate
- Analyse : Forme absente des dix sources consultées. La lèvre est attestée sous soome, que le document retient par ailleurs sous la graphie « some ».
- Sources : S2,S5,S6
- À faire : Probablement une variante non documentée de soome. À soumettre au référent.

**`siga`** — le document dit « taille / hanches »

- Notion attestée : hanche
- Forme attestée : fengeñe
- Analyse : Aucune source ne donne siga pour la taille ou la hanche. ODA ne connaît siga que comme verbe « traverser à gué » et comme nom de personne ; Creissels et Soninkara donnent sòró / soro = faire cuire.
- Sources : S4,S5,S9,S10
- À faire : Écarter siga pour la hanche ; retenir fengeñe sous réserve.

**`Qunyu-bunyi`** — le document dit « coude »

## Deux réserves de méthode

**L'entrée ɲollenme (ODA).** Le relevé donne « calf (leg); mollet » puis « ankle; cheville du pied ». Le fragment consulté est tronqué : le second sens est attribué à ɲollenme, mais cela reste à vérifier sur la page elle-même avant de l'exploiter. Si les deux sens sont confirmés, une seule forme couvrirait le mollet et la cheville — à faire valider, car cela distinguerait nettement ce parler du document, qui les sépare.

**Le trait d'union.** Rien ne garantit que « Kit-qasse » et « kitun qanne » soient le même mot : la correspondance repose sur la composition « main + cou », attestée par deux sources, pas sur une attestation de la forme elle-même.

## Pistes pour trancher

Les dix sources en ligne sont épuisées pour ces formes. Quatre références complémentaires pourraient les départager :

- **Ousmane Moussa Diagana**, Dictionnaire soninké-français (Mauritanie), Karthala, 2013, 5 800 entrées.  
  Décrit le parler de Kaédi (Mauritanie), dont l'alphabet comporte le phonème q — la même orthographe que le document (Qanfe, Qunyu, Kit-qasse). C'est la piste la plus prometteuse pour les formes non résolues. Ouvrage payant (PDF 19,99 €), non consultable en ligne : seuls les liminaires sont en accès libre.
- **Gordon & Sara Williams**, « Des aspects de la lexicologie du Soninke : la dérivation, les mots composés, le changement de transitivité », Dakar, SIL, Cahier de recherche linguistique n° 6, 1998, 92 p. (section « Les mots composés », p. 43-88).  
  Traite explicitement de la composition en soninké. Les formes du document sont des composés écrits avec un trait d'union pédagogique (Kit-qasse, Tange-soro, Tegi-soro) : cet ouvrage est la référence pour en établir l'analyse. PDF accessible sur sil.org/resources/archives/49407 ; la section utile dépasse la limite d'extraction automatique (30 pages) et demande une lecture manuelle.
