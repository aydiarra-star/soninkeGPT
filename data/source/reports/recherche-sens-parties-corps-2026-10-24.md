# Recherche du sens des 54 formes du lexique « parties du corps »

Date : 2026-10-24  
Branche : `arena/89ad8992-soninkegpt`

## Méthode et limites

Chaque forme du document a été confrontée aux sources dictionnairiques et pédagogiques listées plus bas. Aucune traduction n'est extrapolée : une forme non retrouvée est déclarée **non attesté**, et une divergence est déclarée **corrigé** avec ses sources. Les variantes graphiques ne sont pas fusionnées.

Deux réserves à garder en tête. D'abord, ces sources décrivent des variétés différentes du soninké (Kingui au Mali, parlers du Sénégal et de Mauritanie, orthographes SIL et ODA) : une divergence n'est pas forcément une erreur du document. Ensuite, aucune de ces attestations ne remplace la validation du référent : les statuts ci-dessous sont des pistes sourcées, pas des validations.

La page CNRS/LGIDF `lgidf.cnrs.fr/node/680` n'était plus accessible directement : le site renvoie vers `lgmef.huma-num.fr`, où l'ancienne adresse répond 404. Son contenu a été consulté via les résultats de recherche qui l'indexent ; les entrées citées sous **S3** doivent donc être re-vérifiées sur la nouvelle adresse avant toute citation formelle.

### Notes ligne par ligne

- **yime** (tête) — Trois traditions orthographiques pour le même mot.
- **yinte** (cheveux) — Le dictionnaire élargit à « poil, plume ».
- **Giya** (visage) — Une seule source consultée ; à faire confirmer.
- **Teingé** (front) — Graphie « Teingé » non relevée telle quelle ; la forme-source est teŋe/tenŋe.
- **Yaxou** (yeux) — Pluriel de yaaxe.
- **rakke** (bouche) — Alternance dialectale r/l bien documentée sur ce mot.
- **gnougnou** (lèvre) — Forme absente des sources consultées. La lèvre est attestée sous « soome/soomo », variante « some » déjà retenue par le document.
- **some** (lèvre) — « some » = graphie francisée de soome.
- **torro** (oreille) — Variantes toro/taro selon les parlers.
- **yesso** (menton) — Le document place yesso sous « menton ». Les sources attestent yeeso = visage, et le menton est sinqe (variante « sinke » du document).
- **sinke** (menton) — Contredit la base interne du projet, qui rattache sinke au cou.
- **xanné** (cou) — Contredit la base interne du projet, qui rattache xanné à la gorge.
- **xorré** (gorge) — Une seule source consultée ; à faire confirmer.
- **boutte** (cœur) — Divergence majeure : cinq sources indépendantes donnent butte = foie et sondonme = cœur. Le lexique ODA précise aussi les sens dérivés « émotion, colère ».
- **mpallé** (dos) — Le corpus du référent (S7) emploie mpallé, kémpalé et fallé au sens de « puis / ensuite / après ». Le dos est attesté sous xodo/xoodo.
- **siga** (taille / hanches) — Le lexique ODA ne connaît siga que comme verbe et comme nom de personne. La hanche est attestée sous fengeñe.
- **thinkambé** (fesses) — Graphie « thinkambé » non relevée telle quelle ; la forme-source est tinkanbe.
- **Kit'e** (bras) — Le document présente « Kit'e / Kitte » comme une seule entrée « bras / main ». Les sources séparent : kitte = main, xuli = bras / avant-bras, kafe = bras.
- **Kitte** (main) — Le guide SIL glose kitte comme « la main, le bras ».
- **Qanfe** (épaule) — L'épaule est attestée sous kunke. La forme proche de Qanfe est kánpè / kanpe = aile.
- **Kanfe** (épaule) — Même correction que Qanfe.
- **Qunyu-bunyi** (coude) — Forme absente des sources consultées.
- **Kunyu-bunyi** (coude) — Forme absente des sources consultées.
- **Kit-qasse** (poignet) — Le poignet se dit littéralement « cou de la main » (kitte + xanne/qanne). Le second élément « qasse » correspond à cette base « cou » ; la graphie reste à confirmer.
- **Kit-soro** (doigt) — Le doigt est attesté sous doronme ; « kit-soro » se lit comme « doigt de la main ». Le second élément « soro » reste à confirmer.
- **Tegi-soro** (ongle) — Forme absente des sources consultées.
- **Tegi-suuru** (ongle) — Forme absente des sources consultées.
- **Taŋe** (jambe) — Le document fait de Taŋe la « jambe » et de Teingé le « front ». Les sources donnent teŋe / taηe = front pour les deux graphies. La jambe est attestée sous tanxare / tâ.
- **Tange** (pied) — La base est ta (pied, jambe) ; le document note Tange. À faire confirmer avec le référent.
- **Cuute** (cuisse) — Forme absente des sources consultées.
- **Tchuute** (cuisse) — Forme absente des sources consultées.
- **Kuntu-bunyi** (genou) — Forme absente des sources consultées.
- **Kuru** (genou) — Aucune source ne note « kuru » seul ; la forme attestée est xurungo / qúrúngò, dont kuru peut être une réduction. À faire confirmer.
- **Tange-golle** (mollet) — Forme absente des sources consultées.
- **Tange-muru** (cheville) — Forme absente des sources consultées.
- **Tange-soro** (orteil) — L'orteil est attesté sous tandoronme / tandoore ; « tange-soro » se lit comme « doigt de pied ». Graphie à confirmer.
- **Biy'e** (corps) — Le corps est attesté sous fate. Le lexique ODA et la base interne donnent biye = billet (SNK-LEX-0529).
- **Biye** (corps) — Même correction que Biy'e.
- **Guru** (peau) — La peau est attestée sous fate / hate. La forme proche guruɲa désigne le bassin.
- **Kuuru** (peau) — Même correction que Guru.
- **Xill'e** (os) — L'os est attesté sous xotte / qóttè. Aucune source ne note « xill'e » ; le rapprochement repose sur la forme-source xotte.
- **Kille** (os) — kille est la route dans toutes les sources consultées, y compris le corpus du référent et la base interne du projet. L'os est xotte.
- **Yig'e** (sang) — Le sang est attesté sous fare / fore / hòrê. La base yige est le verbe « manger ».
- **Yige** (sang) — Même correction que Yig'e.
- **Tiy'e** (chair / muscle) — Le document écrit « Chaire » ; la forme française est « chair ».
